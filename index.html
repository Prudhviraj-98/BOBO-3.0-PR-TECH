Display Specification

SH1106 OLED Display

Size: 1.3 Inch

Resolution: 128x64

Interface: I2C

Pin Definitions (ESP32-C3 Super Mini)

Component GPIO
OLED SDA GPIO 4
OLED SCL GPIO 5
Control Button GPIO 3
VCC 3.3V
GND GND

How To Build

  1. Connect SH1106 SDA → GPIO 4
  2. Connect SH1106 SCL → GPIO 5
  3. Connect Button → GPIO 3
  4. Connect VCC → 3.3V and GND → GND
  5. Power ESP32-C3 via USB
  6. Click Install Firmware above
  7. Done

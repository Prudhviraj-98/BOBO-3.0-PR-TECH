🔌 Pin Definitions (ESP32-C3 Super Mini)

Component ESP32-C3 Pin
OLED SDA GPIO 4
OLED SCL GPIO 5
Button NEXT GPIO 2
Button PREV GPIO 3
Buzzer GPIO 6
VCC 3.3V
GND GND

🛠 How To Build

  1. Connect OLED (SDA → GPIO4, SCL → GPIO5)
  2. Connect buttons to defined GPIO pins
  3. Connect buzzer to GPIO6
  4. Power ESP32-C3 via USB
  5. Flash firmware using Install button above
  6. Done ✅
